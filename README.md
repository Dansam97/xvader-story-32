An entry for the make.fun bounty [Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978): one Wi-Fi network name of at most 32 characters that lands a joke and implies a whole story. The program writes the name — `SheTookTheKidsAndTheRouter` (26 characters) — to `entry.txt` in the output directory. She left, she took the kids, and she took the router: the network name is the whole divorce, told by the one device that stayed behind.

## Run it

```sh
python3 main.py
```
